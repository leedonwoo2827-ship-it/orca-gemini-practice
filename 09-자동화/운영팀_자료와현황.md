# [가상 실습 자료] 누리에듀 운영팀 자료 목록과 현황 (2026년 12월)

> 누리에듀와 인물은 가상이다. 운영팀 반복 업무는 `반복업무목록.md`를 본다.

## 1. 운영팀 구성
- 박서연(팀장), 김하늘(대리), 최민지(대리), 정다은(주임). 4명.

## 2. 팀이 다루는 자료
| 자료 | 내용 | 들어 있는 정보 |
|---|---|---|
| 회의 녹취 메모 | 주간 회의, 고객사 회의 | 참석자 이름, 가끔 수강생 이름·연락처 |
| 업무일지 | 개인별 하루 업무 기록 | 업무 내용, 가끔 연락처 |
| 교육 문의 메일 | 수강 신청·환불 문의 | 수강생 이름, 이메일, 전화번호 |
| 수강생 명단 | 과정별 신청자 | 이름, 소속, 연락처, 생년월일 |
| 출장비 내역 CSV | 월별 출장비 | 이름, 금액, **계좌번호** |
| 만족도 설문 CSV | 교육 차수별 설문 | 점수, 주관식 (가끔 이름) |
| 교육 안내 공지문 | 홈페이지 게시용 | 공개 정보 |
| 새솔상사 사업 자료 | 착수 보고서, 계약서 | 계약 금액, 고객사 내부 정보 |
