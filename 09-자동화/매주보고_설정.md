# [가상 실습 자료] 매주 주간 보고 자동 작성 설정

## 무엇을
- 지난주 업무일지(`업무일지/` 폴더의 일지 파일)를 읽어 주간 보고 초안을 만든다.
- 실습에서는 날짜를 따지지 말고 폴더 안의 일지 5개(2026-11-30 ~ 12-04)를 모두 읽는다.

## 언제
- 매주 월요일 오전 8시 30분. 출근해서 바로 검토할 수 있게.

## 결과
- 파일: `주간보고/주간보고_YYYYMMDD.md` (YYYYMMDD는 실행한 날짜)
- 형식
  1. 지난주 한 일 (업무별로 묶는다)
  2. 숫자 요약 (교육 문의 건수 합계, 끝낸 일 개수)
  3. 이슈와 도움이 필요한 일
  4. 이번 주 할 일 (일지의 "다음 할 일"에서 모은다)

## 규칙
- 일지에 없는 내용은 쓰지 않는다.
- 일지의 원본은 고치지 않는다.
- 이름 외의 개인정보(연락처 등)는 보고서에 옮기지 않는다.
- 같은 주에 두 번 돌면 파일을 덮어쓰지 말고 끝에 _2를 붙인다.

## 실행 방법 (둘 중 하나)
- 1안: Orca의 봇 예약 기능. Orca가 켜져 있어야 돈다.
- 2안: Windows 작업 스케줄러가 파이썬 스크립트를 돌린다. 스크립트는 .env 의 GEMINI_API_KEY 로 Gemini API를 부른다. Orca가 꺼져 있어도 PC가 켜져 있으면 돈다.
