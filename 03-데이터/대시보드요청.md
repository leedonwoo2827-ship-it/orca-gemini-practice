# 교육 실적 대시보드 요청 메모

> [가상 실습 자료] 실습용으로 지어낸 메모입니다. 실제 회사·인물과 관계없습니다.

- 요청: 박서연 팀장 → 김하늘 대리
- 용도: 매달 팀 회의 때 화면에 띄워 보는 한 장짜리 교육 실적 현황판
- 자료: `교육실적_2026.csv` (같은 폴더)

## 화면 구성 (위에서 아래로)
1. 제목 "2026 사내 교육 실적 (1~10월)"과 기준일
2. 숫자 카드 4개: 총 참가인원, 교육 횟수, 총 교육시간, 평균 만족도
3. 월별 참가인원 차트
4. 부서별 참가인원 차트 (많은 부서부터)
5. 과정별 표: 과정명, 횟수, 참가인원, 평균 만족도

## 지켜 줄 것
- 파일 하나(HTML)로. 인터넷이 없는 회의실 PC에서도 열려야 하니 외부 라이브러리·외부 파일을 쓰지 말 것.
- 데이터 처리: 완전히 같은 행은 1행만, "해외 사업팀"은 해외사업팀으로, 만족도 빈칸은 평균에서만 뺌.
- 글꼴은 맑은 고딕, 숫자는 천 단위 쉼표.
- 화면 아래에 출처 한 줄: "자료: 교육실적 2026 (중복 1행 제외, 부서명 오타 합침)"
