# 설치 점검표 (실습용)

> [가상 실습 자료] 설치를 따라 하며 직접 채우는 점검표입니다. 이 파일은 고치지 말고 복사해서 쓰거나 종이에 적으세요.

| 번호 | 확인할 것 | 확인 방법 | 결과 적기 |
|---|---|---|---|
| 1 | Windows 버전 | 설정 → 시스템 → 정보 | Windows 10 / 11 |
| 2 | Git 설치 | PowerShell에서 `git --version` | 예: git version 2.xx |
| 3 | Git 사용자 이름 | `git config --global user.name` | 비어 있으면 사용자 이름 정하기 단계로 |
| 4 | Git 메일 | `git config --global user.email` | 가짜 주소도 된다 |
| 5 | 실습 저장소 생성 | 파일 탐색기에서 `D:\orca-gemini-practice` | 폴더 8개 |
| 6 | Orca 설치 | 시작 메뉴에서 Orca 실행 | 버전 번호 적기 |
| 7 | 저장소 열기 | Orca 왼쪽 목록에 `01-시작` | 실습 파일이 보이는가 |

## 실습 저장소 8개
`01-시작`, `02-문서`, `03-데이터`, `04-지식검색`, `05-교육콘텐츠`, `06-제안`, `07-미디어`, `08-자동화`

- 오류 메시지 전체(화면 캡처)
- 어느 단계에서 났는지
- 방금 무엇을 눌렀는지
