# 생성형 AI 업무 Assistant 요구 기능 예시 (일반형)

> [가상 실습 자료] 실습용으로 새로 쓴 일반 목록입니다. 특정 기관·회사·입찰 공고의 내용이 아닙니다.
> 여러 조직이 "생성형 AI 기반 업무 Assistant 구축" 사업을 발주할 때 공고에 흔히 들어가는 요구 기능을 일반적인 말로 묶었습니다.

## 1. 문서 작성·요약 (DOC)
| 요구 번호 | 요구 기능 | 설명 |
|---|---|---|
| DOC-01 | 회의록 작성 | 녹취·메모를 정해진 양식의 회의록과 할 일 목록으로 정리한다 |
| DOC-02 | 긴 문서 요약 | 보고서를 3줄·1쪽·임원용처럼 분량과 독자에 맞춰 요약한다 |
| DOC-03 | 보고서·기안문 초안 | 주간 보고, 기안문, 공문 초안을 양식과 문체 규칙에 맞춰 만든다 |
| DOC-04 | 메일 회신 초안 | 받은 메일에 상황과 톤에 맞는 회신 초안을 만든다 |
| DOC-05 | 교정·문체 통일 | 맞춤법과 표기 원칙을 점검하고 바꾼 곳을 표로 보여 준다 |
| DOC-06 | 문서 비교 | 두 버전 문서의 달라진 곳을 변경표로 정리한다 |

## 2. 데이터 분석 (DAT)
| 요구 번호 | 요구 기능 | 설명 |
|---|---|---|
| DAT-01 | 데이터 정리 | 엑셀·CSV의 중복, 형식 불일치, 빈칸을 찾아 정리한다 |
| DAT-02 | 집계·시각화 | 부서별·월별 집계표와 차트, 한 장짜리 대시보드를 만든다 |
| DAT-03 | 설문 분석 | 객관식 통계와 주관식 응답 분류를 함께 정리한다 |
| DAT-04 | 이상치 점검 | 입력 오류와 튀는 값을 찾아 점검표로 만든다 |

## 3. 사내 지식 검색 (KNW)
| 요구 번호 | 요구 기능 | 설명 |
|---|---|---|
| KNW-01 | 규정 질의응답 | 사내 규정·매뉴얼을 근거로 답하고 근거 조항을 함께 보여 준다 |
| KNW-02 | FAQ 생성 | 문의 기록에서 자주 묻는 질문과 답을 뽑는다 |
| KNW-03 | 근거 검증 | AI 답의 문장마다 원문 근거가 있는지 표시한다 |

## 4. 번역 (TRN)
| 요구 번호 | 요구 기능 | 설명 |
|---|---|---|
| TRN-01 | 문서 번역 | 한국어와 영어 등 외국어 문서를 서로 번역한다 |
| TRN-02 | 용어집 기반 번역 | 조직의 용어집을 지켜 번역하고 표기를 통일한다 |
| TRN-03 | 다국어 메일 | 해외 협력 기관에 보낼 메일을 외국어로 쓰고 역번역으로 확인한다 |

## 5. 콘텐츠 생성 (CNT)
| 요구 번호 | 요구 기능 | 설명 |
|---|---|---|
| CNT-01 | 교육 콘텐츠 | 강의계획서, 강의 대본, 평가 문항을 만든다 |
| CNT-02 | 홍보 콘텐츠 | 공지문, 보도자료, 카드뉴스 문구를 만든다 |
| CNT-03 | 이미지 생성 | 홍보·교육용 이미지를 생성한다 |
| CNT-04 | 음성·영상 처리 | 녹음 받아쓰기, 영상 요약, 자막 파일을 만든다 |

## 6. 자동화 (AUT)
| 요구 번호 | 요구 기능 | 설명 |
|---|---|---|
| AUT-01 | 반복 업무 템플릿 | 자주 하는 요청을 저장해 두고 다시 쓴다 |
| AUT-02 | 예약 실행 | 정기 업무를 정해진 시간에 자동으로 돌린다 |
| AUT-03 | 업무 도구 연계 | 메일·메신저·문서 저장소와 연결해 결과를 전달한다 |

## 7. 보안·거버넌스 (SEC)
| 요구 번호 | 요구 기능 | 설명 |
|---|---|---|
| SEC-01 | 개인정보 보호 | 개인정보를 찾아 가리거나 가명 처리한 뒤 작업한다 |
| SEC-02 | 권한 관리 | 사용자·부서별로 볼 수 있는 자료 범위를 나눈다 |
| SEC-03 | 사용 기록 | 누가 어떤 요청을 했는지 기록을 남긴다 |
| SEC-04 | 사람 검토 | AI 결과물은 사람이 확인한 뒤에 내보낸다 |

---

### 참고: 이 과정의 기능 영역
공고마다 묶는 방식이 다릅니다. 이 과정은 기능을 **문서·데이터·지식·콘텐츠·미디어·자동화** 6개 영역으로 나눠 배웁니다.
보안·거버넌스는 따로 떨어진 영역이 아니라 6개 영역 모두에 적용하는 공통 기준으로 봅니다.
