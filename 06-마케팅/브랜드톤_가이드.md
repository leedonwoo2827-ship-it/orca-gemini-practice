# 누리에듀 브랜드 톤 가이드 (요약본)

> [가상 실습 자료] 누리에듀(가상 회사) 마케팅 실습용으로 지어낸 내용입니다. 실제 회사·인물과 관계없습니다.

관리: 정다은(홍보) / 개정: 2026-11

## 1. 한 문장 브랜드
"내일 업무에 바로 쓰는 배움"

## 2. 말투
| 채널 | 말투 | 예 |
|---|---|---|
| SNS 카드뉴스 | 해요체 | "회의록 정리, 같이 해 봐요" |
| 블로그 | 합니다체 | "오늘은 회의록 정리를 다룹니다" |
| 뉴스레터 | 합니다체, 정중하게 | "담당자님께 안내드립니다" |

- 독자를 "여러분" 또는 "직장인"으로 부른다. "고객님"은 쓰지 않는다.
- 한 문장은 30자 안팎. 길면 둘로 나눈다.
- 영어는 꼭 필요한 말(AI 등)만 쓴다. "인사이트", "솔루션", "레버리지"는 쓰지 않는다.

## 3. 하지 않는 것
- 겁주기: "AI 못 쓰면 뒤처진다", "곧 일자리를 잃는다"
- 과장: "최고", "완벽", "무조건", "100%", "누구나 하루 만에"
- 근거 없는 숫자: 12월_마케팅일정.md 4절 "콘텐츠에 써도 되는 사실"에 없는 숫자
- 느낌표: 카드 한 장에 1개까지
- 이모지: 카드 한 장에 1개까지, 제목에는 쓰지 않음

## 4. 카드뉴스 규칙
- 크기 1080×1080. 6장 한 묶음.
- **한 장에 한 메시지.** 제목 20자 이내, 본문 3줄 이내 (한 줄 20자 안팎).
- 1장: 표지 (질문이나 공감으로 시작). 6장: 행동 안내 (무엇을, 언제까지).
- 여백: 바깥 여백 80px 이상. 글자가 카드 면적의 절반을 넘지 않게.
- 글자 크기: 제목 64px 이상, 본문 36px 이상.
- 6장 하단에 "누리에듀" 글자 표시 (로고 이미지는 쓰지 않음).

## 5. 색
| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 남색 | #1E3A5F | 제목, 본문 글자 |
| 주황 | #F28C28 | 강조 단어, 버튼, 쪽 번호 (한 장에 한 곳만) |
| 크림 | #FFF8F0 | 배경 |
| 회색 | #6B7280 | 보조 글자 |
