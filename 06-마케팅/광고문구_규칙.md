# 광고 문구 규칙 (누리에듀 홍보팀)

> [가상 실습 자료] 누리에듀(가상 회사) 마케팅 실습용으로 지어낸 내용입니다. 실제 회사·광고 심의 기준과 관계없습니다.

관리: 정다은(홍보) / 승인: 박서연(팀장) / 개정: 2026-11

## 1. 글자 수 (공백 포함)
| 자리 | 최대 |
|---|---|
| 검색 광고 제목 | 15자 |
| 검색 광고 설명 | 45자 |

- 글자 수는 눈으로 세지 않는다. 도구로 센 숫자를 적는다.

## 2. 쓰지 않는 표현
| 종류 | 표현 |
|---|---|
| 최상급·순위 | 최고, 최초, 1위, 유일, 국내 최대, 가장 |
| 단정·보장 | 100%, 무조건, 보장, 완벽, 반드시 |
| 결과 과장 | 단 하루 만에, 누구나 쉽게, 업무 시간 절반, 칼퇴 보장, 효율 2배 |
| 겁주기 | AI 못 쓰면 뒤처진다, 지금 안 하면 늦는다 |
| 거짓 긴급 | 마감 임박, 오늘만 (실제 마감 3일 전부터만 "마감 ○일 전"을 쓸 수 있다) |
| 비교·비방 | 다른 회사 이름, "타사보다", "다른 강의와 달리" |

## 3. 숫자와 사실
- 숫자는 `과정소개_랜딩용.md`에 있는 것만 쓴다.
- 수료율·만족도를 쓸 때는 "베타 운영 기준"을 함께 쓴다.
- 후기는 원문 그대로 인용하고, 줄이거나 바꾸지 않는다.

## 4. 가격과 무료
- 할인가를 쓸 때는 정가, 기간, 대상을 함께 쓴다. 예) "정가 99,000원 → 79,200원 (12/7~12/20, 개인)"
- 글자 수가 모자라 함께 못 쓰면 할인가를 빼고 쓴다.
- "무료"는 범위를 밝힌다. "무료 강의"(X) → "1·2차시 무료 맛보기"(O)
