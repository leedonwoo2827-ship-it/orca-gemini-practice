# 학습 내용: 2차시 「좋은 요청문의 4요소」

> [가상 실습 자료] 누리에듀(가상 회사) 실습용으로 지어낸 내용입니다. 실제 회사·인물·과정과 관계없습니다.

- 과정: 신입사원 생성형 AI 활용 기초 (4차시 중 2차시)
- 작성: 이준호(콘텐츠) / 문항 출제: 최민지(평가)

## 학습목표
1. 요청문의 4요소(목적·자료·형식·검토 기준)를 구분할 수 있다.
2. 4요소가 빠진 요청문에서 빠진 요소를 찾을 수 있다.
3. 업무 상황에 맞게 4요소를 갖춘 요청문으로 고쳐 쓸 수 있다.

## 1. 요청문이란
요청문은 AI에게 일을 맡길 때 보내는 글이다. AI는 요청문에 적힌 것만 안다. 적지 않은 부분은 AI가 짐작해서 채운다. 짐작이 많을수록 결과가 원하는 것과 멀어진다.

## 2. 4요소
### 2-1. 목적
- 뜻: 결과를 어디에, 누구에게 쓸지 알려 주는 것.
- 예: "팀장님께 보고할 회의록이에요.", "신입사원 안내 메일에 넣을 문단이에요."
- 효과: 같은 자료라도 목적에 따라 길이와 말투가 달라진다. 임원 보고용이면 짧게, 실무자 공유용이면 자세하게 쓴다.

### 2-2. 자료
- 뜻: 무엇을 보고 만들지 정확히 짚어 주는 것.
- 예: "운영점검회의_녹취메모.txt 를 읽고", "3월 실적 시트만 보고"
- 요령: 파일 이름을 그대로 적는다. "그 파일", "아까 자료"처럼 쓰면 AI가 다른 파일을 볼 수 있다.

### 2-3. 형식
- 뜻: 결과의 모양을 정해 주는 것.
- 예: "표 하나로, 열은 할 일·담당자·마감일", "3줄 요약", "회의록_1123.md 파일로 저장"
- 요령: 분량(몇 줄, 몇 쪽), 모양(표, 목록, 문단), 저장 방법(파일 이름)을 적는다.

### 2-4. 검토 기준
- 뜻: 결과가 지켜야 할 조건. 사람이 결과를 검토할 때 쓰는 기준이기도 하다.
- 예: "메모에 없는 내용은 쓰지 마.", "숫자는 원문 그대로.", "날짜와 이름은 메모 그대로."
- 요령: 틀리면 곤란한 것을 적는다. 대개 숫자, 날짜, 이름, 없는 내용 지어내기다.

## 3. 흔한 실수
| 실수 | 예 | 빠진 요소 |
|---|---|---|
| 한 줄로만 맡긴다 | "회의록 정리해 줘." | 목적·자료·형식·검토 기준 모두 |
| 파일을 짚지 않는다 | "회의록을 표로 정리해 줘. 메모에 없는 내용은 쓰지 마." | 자료 |
| 모양을 정하지 않는다 | "보고서를 읽고 요약해 줘." | 형식 |
| 지킬 것을 말하지 않는다 | "보고서를 3줄로 요약해 줘." | 검토 기준 |
| 막연한 기준을 쓴다 | "좋게 써 줘.", "팀장님이 좋아하게" | 검토 기준 (확인할 수 없는 기준은 기준이 아니다) |

## 4. 고쳐 쓰기 예
- 고치기 전: "설문 결과 정리해 줘."
- 고친 뒤: "팀장님께 보고할 자료예요. 만족도설문.csv 를 읽고 1쪽 요약을 요약_설문.md 로 만들어 줘. 숫자는 원본과 같아야 하고, 근거 없는 해석은 빼 줘."
- 살펴보기: 목적(팀장 보고) · 자료(만족도설문.csv) · 형식(1쪽, 파일 이름) · 검토 기준(숫자 일치, 근거 없는 해석 금지)

## 5. 보내기 전 점검 질문
1. 어디에 쓰는가? (목적)
2. 무엇을 보는가? (자료)
3. 어떤 모양인가? (형식)
4. 무엇을 지키는가? (검토 기준)

## 6. 정리
- 4요소를 갖추면 요청문은 길어진다. 그래도 여러 번 고쳐 달라고 하는 것보다 빠르다.
- 검토 기준은 AI에게 주는 조건이면서, 사람이 결과를 확인하는 점검표다.
