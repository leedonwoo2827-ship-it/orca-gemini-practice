# 슬라이드 규칙 (여백 있는 HTML 슬라이드)

> [가상 실습 자료] 누리에듀(가상 회사) 실습용 규칙입니다. 이 강의 시리즈의 슬라이드도 같은 규칙으로 만듭니다.

## 1. 내용
- 한 장에 메시지 하나만 담는다.
- 항목은 한 장에 **최대 3개**다.
- 한 항목은 **18자 안팎**의 짧은 구절로 쓴다. 문장으로 쓰지 않는다.
- 설명은 말(내레이션)이 맡는다. 슬라이드에 다 쓰지 않는다.
- 원고가 넘치면 줄이지 말고 **장을 나눈다**. 원고에 없는 내용은 넣지 않는다.

## 2. 장 모양 (하나를 골라 쓴다)
| 모양 | 쓰는 곳 |
|---|---|
| 표지 | 첫 장. 제목과 부제 |
| 한 문장 | 장면, 핵심 메시지 |
| 카드 | 나란한 항목 2~3개 |
| 단계 | 순서가 있는 3~4단계 |
| 요청문 상자 | 채팅에 보낼 요청문 |
| 주의 | 꼭 지킬 것 |
| 정리 | 마지막 장. 요약과 다음 시간 |

## 3. 화면
- 16:9, 1920×1080 기준. 브라우저 창 크기가 바뀌어도 비율을 유지한다.
- 넉넉한 여백: 화면 가장자리에서 안쪽으로 8% 이상 비운다.
- 큰 글씨: 제목 72px 이상, 본문 40px 이상 (1920×1080 기준).
- 색은 배경 1, 글자 1, 강조 1로 3가지 안쪽.
- 한 파일(slides.html)로 만든다. 외부 라이브러리와 외부 글꼴을 쓰지 않는다.
- 키보드 ←, → 로 넘긴다. 오른쪽 아래에 "현재 장 / 전체 장"을 작게 표시한다.

## 4. 넘침 점검
- 어떤 장도 내용이 화면 밖으로 넘치거나 스크롤이 생기면 안 된다.
- 넘친 장은 글씨를 줄이지 말고 장을 나눈다.
