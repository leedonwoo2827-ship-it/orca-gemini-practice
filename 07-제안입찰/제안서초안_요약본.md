# [가상 실습 자료] 새솔상사 업무 Assistant 제안서 초안 (요약본, 2027년 1월 21일)

> 누리에듀(가상)가 새솔상사(가상)에 내는 기술 제안서의 장별 요약본이다. 자가 점검 연습용이다.

## Ⅰ. 사업 이해
새솔상사 임직원은 회의록, 보고서, 엑셀 집계, 규정 찾기에 많은 시간을 쓴다. 일부 직원이 개인 계정으로 외부 AI를 쓰고 있어 자료 유출 위험도 있다. 누리에듀는 이 사업의 핵심을 "편리함과 안전함을 함께 갖춘 업무 Assistant"로 이해한다. 시범 부서 3곳(경영지원팀, 영업관리팀, 교육팀)의 업무를 먼저 진단하고, 효과가 큰 기능부터 도입한다.

## Ⅱ. 추진 전략과 방법론
- 전략 1: 공개 도구 조합. Orca와 Gemini 에이전트를 조합해 별도 개발 없이 빠르게 시작한다.
- 전략 2: 업무별 요청문 표준화. 자주 쓰는 요청을 레시피로 만들어 누구나 같은 품질을 얻게 한다.
- 전략 3: 안전한 사용 습관. 데이터 등급과 가명 처리를 교육 첫 시간에 다룬다.
- 추진 일정: 착수(3월) → 진단·설계(3~4월) → 구축(4~5월) → 교육·이용 지원(6~8월) → 완료 보고(9월 30일)

## Ⅲ. 기능 구현 방안
| 요구 ID | 구현 방안 |
|---|---|
| SFR-001 | 녹취 메모와 녹음 파일로 회의록·할 일 목록 생성, 원본 대조 단계 포함 |
| SFR-002 | 새솔상사 양식 파일을 저장소에 넣고 양식대로 초안 작성 |
| SFR-003 | 중복·오류 점검표 → 집계표 → 차트, 검산 단계 포함 |
| SFR-004 | 규정 폴더를 근거로 조항 번호가 붙은 답, 근거 검증 |
| SFR-006 | 스캔·캡처 이미지 → 표 → 원본 대조 |
| SFR-007 | 미디어 기능 제공 |
| SFR-008 | 레시피 폴더와 예약 실행으로 주간 보고 자동화 |

## Ⅳ. 보안·데이터 거버넌스
- 데이터 등급은 공개 / 내부 / 민감 3등급으로 나눈다. 민감 등급은 AI에 넣지 않고, 내부 등급은 가명 처리 후 넣는다. (DAR-001, DAR-002)
- API 키는 `.env` 파일에만 두고 공유 대상에서 뺀다. (SEC-001)
- 부서별 저장소를 나눠 접근 범위를 분리한다. (SEC-003)
- 이용 지원 시작 2주 전에 새솔상사의 보안 점검을 받는다. (SEC-004)

## Ⅴ. 교육과 운영 지원
- 사용자 교육: 기본 4시간, 심화 4시간. 기본 교육은 부서별로 3회 나눠 운영한다. 대상은 임직원 150명이다. (SER-001)
- 이용 지원: 메신저 채널 1개와 주 1회 원격 상담 시간. (SER-002)
- 기능별 1쪽 매뉴얼과 기능마다 요청문 예시 3개. (SER-003)
- 월간 이용 현황 보고: 월 이용자 수, 기능별 사용 횟수, 문의 유형. (SER-004)
- 수행 경험: 한결물산 AI 활용 교육(수강 520명, 수료율 86.9%, 만족도 4.6점).

## Ⅵ. 사업 관리와 투입 인력
- 사업 책임자 박서연(경력 14년)이 전체를 관리한다.
- 투입 인력 6명, 총 15.0 M/M.
- 착수 보고는 계약 후 10일 안에 한다. (PMR-001)
- 기대 효과: 업무 효율이 크게 향상될 것이다.
