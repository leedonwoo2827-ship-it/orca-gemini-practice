# [가상 실습 자료] 새솔상사 제안 발표 준비 메모 (박서연, 2027년 1월 28일)

## 1. 발표 조건 (발주사 안내)
- 일시: 2027년 2월 3일(수) 10:30, 새솔상사 본사 5층 회의실
- 발표 15분 + 질의응답 10분. 시간을 넘기면 발표를 끊는다.
- 발표자: 박서연(사업 책임자). 질의응답에는 2명까지 함께 들어갈 수 있다.
- 평가위원(가상): 경영지원본부장, 정보보안 담당 차장, 교육팀장, 외부 위원 2명

## 2. 슬라이드 규칙
- 10장 이내. 한 장에 메시지 하나.
- 글자는 크게, 여백은 넉넉히. 한 장에 항목은 3개까지.
- 1분 시연 자리를 한 장 둔다: 녹취 메모 → 회의록 생성 장면(녹화 영상으로 대신할 수 있음).
- 숫자는 제안서에 있는 것만 쓴다.

## 3. 꼭 전할 메시지 3개
1. 별도 개발 없이 공개 도구 조합으로 빠르게 시작한다. 그래서 가격 부담이 낮다.
2. 데이터 등급(공개·내부·민감)과 가명 처리로 안전하게 쓴다.
3. 교육과 레시피로 누구나 같은 품질을 얻는다.

## 4. 걱정되는 질문 (팀 회의에서 나온 것)
- "자체 솔루션이 없는데 사업이 끝나면 누가 관리하나?"
- "외부 AI에 우리 자료가 학습되지 않나?"
- "교육 대상이 120명인가 150명인가?"
- "효과를 어떻게 숫자로 보여 줄 건가?"

## 5. 제안서에서 쓸 수 있는 숫자
- 사업 기간 6개월(2027. 3. 2. ~ 8. 31.), 투입 6명 15.0 M/M
- 교육: 기본 4시간 + 심화 4시간, 기본은 부서별 3회
- 실적: 한결물산 AI 활용 교육 수강 520명, 수료율 86.9%, 만족도 4.6점
- 이용 지원: 메신저 채널 + 주 1회 원격 상담, 월간 이용 현황 보고 3회
- 효과 지표: 회의록 작성 시간, 주간 보고 작성 시간, 월 이용자 수 (진단 때와 종료 때 측정)
