# 제미나이와 오르카로 만드는 나만의 AI 업무 비서: 실습 파일

에이전트 작업 도구 **Orca**와 **Gemini**로 업무 Assistant 기능을 하나씩 만들어 보는 강의의 실습 파일입니다.
**회사·인물·자료는 모두 실습용으로 만든 가상 예시입니다.**

## 쓰는 법 (Windows)

1. [Git for Windows](https://git-scm.com/download/win)를 설치합니다.
2. 이 페이지의 **Code → Download ZIP**으로 내려받아 압축을 풉니다.
3. 압축을 푼 폴더에서 PowerShell을 열고 실행합니다.
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\setup-practice.ps1
   ```
   `D:\orca-gemini-practice` 아래에 실습 저장소 9개가 만들어집니다. D 드라이브가 없으면 `-Target C:\orca-gemini-practice`를 붙입니다.
4. Orca에서 **프로젝트 추가 → 폴더 찾아보기**로 `01-시작` 같은 폴더를 엽니다.

> 실습하다 처음 상태로 되돌리고 싶으면 `-Force`를 붙여 다시 실행합니다. (`.env` 파일은 남습니다.)

## 폴더

| 폴더 | 영역 |
|---|---|
| `01-시작` | 업무 Assistant 소개, 첫 채팅, 요청문, 데이터 등급 |
| `02-문서` | 회의록, 보고서 요약, 주간 보고, 기안문, 메일, 교정, 문서 비교 |
| `03-데이터` | 엑셀 정리, 집계, 설문, 파일 합치기, 대시보드 |
| `04-지식검색` | 규정 질의응답, FAQ, 웹 리서치 |
| `05-교육콘텐츠` | 강의계획서, 대본, 문제, 자막 |
| `06-마케팅` | 홍보 문구, 카드뉴스, GEO 진단 |
| `07-제안입찰` | 제안요청서 분석, 제안서, 평가표, 발표 자료 |
| `08-미디어` | 이미지, 스캔 문서, 녹음·영상 요약 |
| `09-자동화` | 레시피, 예약 실행, 공유와 거버넌스 |

실습 파일은 강의 진행에 맞춰 바뀔 수 있습니다.
