# 기안문 양식과 문체 규칙 (누리에듀 운영팀)

> [가상 실습 자료] 가상의 회사 누리에듀의 내부 양식입니다. 실제 기관의 공문 규정이 아닙니다.

## 1. 기안문 양식
아래 제목과 순서를 그대로 쓴다.

```
문서번호: 운영팀-2026-(결재 후 부여)
수신: 내부결재
제목: (무엇을 하려는지 한 줄)

1. 관련: (근거 문서 이름과 문서번호)
2. 목적: (한두 줄)
3. 세부 내용
  가. 교육명:
  나. 일시:
  다. 장소:
  라. 대상:
  마. 강사:
  바. 소요 예산:
4. 예산 과목:

붙임  1. (붙임 문서) 1부.
      2. (붙임 문서) 1부.  끝.
```

## 2. 문체 규칙 8가지
| 번호 | 규칙 | 맞는 예 | 틀린 예 |
|---|---|---|---|
| R1 | 개조식으로 쓰고 문장 끝은 "~함", "~임", "~바람"으로 맺는다 | 초빙하고자 함 | 초빙하려고 합니다 |
| R2 | 날짜는 "2026. 12. 10.(목)" 형식으로 쓴다 | 2026. 12. 10.(목) | 12월 10일, 2026-12-10 |
| R3 | 시간은 24시간제 "14:00~17:00"으로 쓴다 | 14:00~17:00 | 오후 2시~5시 |
| R4 | 금액은 "금700,000원(금칠십만원)"처럼 숫자와 한글을 함께 쓴다 | 금50,000원(금오만원) | 5만 원 |
| R5 | 항목 기호는 1. → 가. → 1) → 가) 순서로 쓴다 | 3. 아래 가. | 3. 아래 - 또는 ① |
| R6 | 영문 약어는 처음 나올 때 풀어 쓴다 | LMS(학습관리시스템) | LMS |
| R7 | 감정 표현, 느낌표, 구어체를 쓰지 않는다 | 참석 바람 | 꼭 참석해 주세요! |
| R8 | 본문 마지막(붙임이 있으면 붙임 끝)에 "끝."을 쓴다 | …1부.  끝. | 끝 표시 없음 |

## 3. 사내 외부 강사료 기준 (발췌)
| 구분 | 첫 1시간 | 1시간을 넘는 시간(1시간마다) |
|---|---|---|
| 대표·교수급 | 300,000원 | 200,000원 |
| 실무 전문가급 | 200,000원 | 150,000원 |

- 교통비는 실비로 주되, 1회 50,000원을 넘지 않는다.
- 강사료는 소득세·지방소득세 3.3%를 떼고 지급한다. 기안문의 소요 예산에는 떼기 전 금액을 쓴다.
